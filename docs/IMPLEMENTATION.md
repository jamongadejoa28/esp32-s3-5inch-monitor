## 통신 해석

- PDU 주소: 코일 `문서 주소 - 1`, 홀딩 `4xxxx - 40001`.
- `40005`는 하위 바이트만 운전 상태이며 상위 바이트는 지연 상태다.
- `40006..40008`은 단계 비트필드이며 비례 퍼센트 값으로 읽지 않는다.
- 경보는 컨트롤러의 `40003/40004` 판정 워드를 사용한다. 패널 LED 비트를 경보로 해석하지 않는다.
- PDF의 코일 R 표기와 기존 시스템 FC05 구현은 다르다. FC05 사용은 기존 구현을 따른 것이며 모든 출력의 실제 기기 지원 여부는 현장 시험 대상이다.
- 온도/습도 그래프의 결측 구간은 0값으로 채우지 않는다. 장기 그래프는 고정 시간 구간으로 집계하고 최소/최대를 함께 보관한다.
- 오프라인 자동 적용은 40012..40019의 목표 설정값만 지원한다. 주소별 대기값을 NVS에 보존하고 재조회 일치 후 지운다. 운전/정지·코일 명령은 대기 저장하지 않는다.
- 배터리 없는 RTC의 완전한 전원 차단 뒤에는 PC 시간 동기화 또는 수동 입력이 필요하다. 공장 초기값·발진 정지·잘못된 날짜는 유효한 현재 시각으로 사용하지 않는다.

## 실물 인수 확인

1. 보드 부팅, 색상, 터치 4모서리, RTC 재부팅 유지, 절전/복귀.
2. 장비번호/온습도/입출력/경보를 기존 모니터와 대조.
3. 설정 읽기 → 변경 → FC06 응답 및 재조회 → 원래 값 복원.
4. 운전/정지, 2호만 운전 등 개별 상태와 애니메이션 대조.
5. 정지 상태에서 FC05 급수/배수 및 출력 테스트 후 원래 상태 복원.
6. 케이블 분리/복구, 응답 유실, 전원 차단 후 기록 복구, 스케줄 경계 확인.

경보해제는 모니터 알림 확인이며 컨트롤러 리셋이 아닙니다. 다음 신규 유효 응답에 같은 경보가 남으면 재표시합니다. 실제 정상 복귀는 현재 경보에서 자동 제거하고 이력에 해제로 남깁니다. 통신 끊김은 정상 복귀로 취급하지 않습니다. 이력 삭제는 장비 주소별 NVS 삭제 기준점을 기록하며 현재 경보와 추세 기록을 보존합니다.
